## 1. 一句话目标与空间体验闭环

让第一次来的人在 **30 秒内**被大槐树树洞的暖光吸引，点击树洞走进果核镇认识 8 颗水果、进入喜欢的角色房间做客，并愿意把“今天没被看见的小事”投进**果核投递箱**，收到一枚角色的果实火漆印章与一句不评判的回应。

网站是社交账号（每周 2 次短篇漫画 + 15 秒动画）的沉浸式落脚处：账号负责被刷到，网站通过“**洞口 → 阵容 → 房间 → 投递箱**”的空间旅程把短暂心动沉淀为温柔陪伴。

```text
社媒短漫 / 15 秒动画引流
   ↓
[首页 · 大槐树树洞入口] 逆光森林与发光树洞 → 点击树洞触发暖光推进互动（≤1s，可跳过）
   ↓
[角色阵容卡片] 走进树洞，看到 8 颗水果与“我像谁”筛选 → 挑选心仪角色
   ↓
[角色专属房间 ×8] 点击角色卡片进入对应的据点房间 → 看场景/表情/姿势/档案/周边展柜
   ↓
[果核投递箱 & 留声板] 投递小事收果实火漆印章 / 浏览精选留声轻拍共鸣 → 存图分享回流
```

## 4. 核心交互、边界与特殊状态规范

### 4.1 树洞穿梭、阵容筛选与房间进出

- **首页树洞互动**：点击树洞触发的暖灯亮起与镜头推进转场**严格 ≤ 1 秒**，固定提供“跳过”入口；开启系统“减少动态效果（`prefers-reduced-motion`）”时直接无动画跳转至角色阵容页。
- **阵容页“我像谁”筛选**：选中性格一词或生活能力后，匹配角色卡片轻微上浮并点亮单一主色柔光描边，其余未命中卡片平滑淡化至低透明度（约 `0.32`）而不移除占位，呼应“不把没被选中当笑话”。
- **进入角色房间**：点击角色卡片触发柔和暖光展开过渡（`≤ 600ms`，支持减少动态降级），支持浏览器原生返回键回到树洞阵容页并恢复上次筛选状态。
- **表情与姿势**：同角色 ≥5 张表情图画布尺寸与面部锚点严格一致，预加载切换零偏移零闪烁；姿势灯箱支持点击遮罩、关闭按钮与 `Esc` 键关闭。

### 4.2 果核投递箱规则与安全兜底

- **3 步 / 30 秒闭环**：打开投递 → 输入 ≤100 字并选定角色 → 约 1 秒火漆盖章动效获取回执。
- **回复文案库**：全部预先编写并经人工审核（每角色 ≥10 条），**严禁实时 AI 生成**；只用“会说的话”陪伴句式（“先歇一下”“我陪你想想”“这个不归你扛”），严禁说教与否定式安慰（“你可以的”“别人都行”“别想太多”）。
- **安全与隐私兜底**：前端本地检测自伤、辱骂或手机号/邮箱/身份证等个人信息；命中时不盖章，平滑切换为温和关怀提示与正规求助入口。投递不收集姓名和联系方式，他人投递永久不公开展示。

### 4.3 果核留声板无压互动规则

- 全部明信片由团队静态 JSON 人工编审，**无自由发帖、无评论输入框、无审核后台依赖**；
- 贴纸反馈仅本地记录与展示印记，**全站不统计、不展示贴纸总数、点赞数或热度排序**。

### 4.4 值班轮换、更新日历与午夜静默态

- **今日值班算法（已定稿）**：8 个角色**按自然日顺序循环值班（每 8 天一轮）**；前端按用户本地日历日期 `YYYY-MM-DD` 转为 UTC 零点计算整天差，再取模 `((dayDiff % 8) + 8) % 8`，避免夏令时与跨时区偏移误差。
- **更新日历**：已发布短漫支持顺滑阅读，15 秒动画支持静音预览与手动播放；未发布条目仅展示角色与一句话预告。
- **午夜静默态（00:00–06:00）**：不弹任何提醒或推送；页眉微光提示“小镇已熄灯，果实们正在做梦”，树洞与房间维持安静低刺激暖灯氛围。

## 5. 视觉与设计系统规范（柔和植绒微缩定格风 · 暖光森系树洞）

本节直接提炼自参考图的电影级微缩定格动画美学，转化为纯 CSS 可落地的统一设计系统，所有变量全部定义于 `css/common.css`。

### 5.1 视觉气质与材质 DNA

- **材质与光影语言（精准对齐参考图）**：
  - **角色质感**：**柔和植绒/微磨砂定格动画模型感**——造型圆润饱满、带真实果皮纹理（菠萝菱格、草莓籽点、葡萄果珠、水蜜桃绒感）与柔和漫反射高光，搭配做旧帆布小邮包与小鞋；拒绝粗糙毛线质感或扁平廉价“泛用萌系水果”，绝不混入既有 IP。
  - **环境调性**：林间逆光透亮的嫩绿树叶 + 苔藓与野花点缀的石阶 + 温润焦糖树皮与树干菌菇（外部暖日光），自然过渡到老槐树洞内的深胡桃木壁 + 复古琥珀小吊灯 + 远端圆格木窗微光（内部包裹感），完美衬托出 8 颗水果各自纯净鲜明的高饱和主色。
  - **手工 UI 细节**：参考图树干雕刻木牌 → 转化为角色据点门牌角标；柔和微绒暖奶油卡片 + 多层暖棕漫射阴影 + 果实火漆印章 + 轻量 CSS 金色光尘。
- **四层空间海拔体系**：
  - **Level 0 · 画布与树洞层**（`--bg-canvas` / `--bg-wood-deep`）：常规页面采用柔暖日光奶油底，树洞入口/穿梭过渡与房间沉浸舞台衔接深胡桃暖木与林间日光；
  - **Level 1 · 柔绒卡片层**（`--bg-surface` + `--shadow-card`）：角色阵容卡、留声板明信片、房间四栏档案卡；
  - **Level 2 · 悬浮暖光层**（`--bg-surface-translucent` + `--shadow-float`）：吸顶毛玻璃导航、首屏双联焦点卡（今日值班破框立绘卡 / 投递箱卡）；
  - **Level 3 · 舞台与弹层**（`--shadow-modal`）：火漆盖章回执卡、姿势放大灯箱、短漫/动画弹层。

### 5.3 核心组件与交互状态精细规范

- **树洞入口光晕热区**：百分比定位于大槐树洞口的琥珀呼吸光晕与“走进树洞”胶囊，桌面与手机端均保持大热区、不随视口缩放偏移。
- **手工木牌角标**：呼应参考图中树干上的木牌质感，用于角色阵容卡片的据点房间标识与角色房间顶部吸顶门牌。
- **角色阵容卡片**：`--radius-lg` 柔绒暖白卡，上部定稿角色留白展示 + 木牌角标 + 底部单一主色性格胶囊与“去 ta 的房间坐坐”轻引导。
- **破框值班卡**：首页今日值班角色立绘顶部微探出卡片上缘 `16px–24px`，增添微缩立体感（手机端预留顶部安全间距防遮挡）。
- **五态完备与加载兜底**：全部交互元素完备定义 `default / hover / active / focus-visible / disabled` 五态；`focus-visible` 使用清晰琥珀暖光外环支持键盘操作；图片加载中显示暖奶油微光骨架并声明 `aspect-ratio` 消除布局抖动。

### 5.4 角色呈现、微动效与无障碍红线

- **识别点先于装饰**：先认出水果，再记住名字。每个角色的固定项（外轮廓、配饰位置、单一主色）全站锁定不变，可变项仅限表情、动作与小情绪符号；手机端缩略卡尺寸下表情仍清晰可辨。
- **对比度与非单色承载**：正文对比度 ≥ WCAG AA（`4.5:1`），深木底（`--bg-wood-deep`）上使用高可读 `--text-on-wood`，浅黄类主色（菠萝黄、柚黄、佛手柑黄）胶囊配深色主文 `--text-primary`；**代表色绝不单独承载信息**，必须同时配合文字或图标。
- **微动效降级**：树洞穿梭、金色光尘、房间展开与盖章动效均遵循 `@media (prefers-reduced-motion: reduce)` 自动减弱位移与闪烁。

## 7. 分维验收与完成标准

- **空间动线与体验验收**
  - 找 5 位 18–30 岁用户试看首页 30 秒，至少 4 位能说出“这是水果角色的小镇”并记住至少 1 个角色名；
  - 首页树洞点击热区在桌面与手机（`390px`）均精准贴合洞口且角色无错误裁切，点击流畅触发 ≤1 秒暖光推进互动并进入角色阵容页（支持跳过与减少动态降级）；
  - 阵容页点击任意 1 张角色卡片均可顺畅进入该角色对应的专属房间，返回流畅且筛选状态保留；
  - 投递箱从点击到收到火漆盖章回复不超过 **3 步、30 秒**，导出 `3:4` 分享图清晰且隐私开关生效；
  - 首页按自然日 8 天循环准确轮换今日值班角色（跨时区/夏令时无偏移）；果核留声板支持浏览明信片与无计数本地贴纸反馈。
- **内容与美术一致性验收**
  - 首页树洞主视觉定稿图与世界观设定完全一致（**包含全部 8 颗水果、无遗漏角色**）；
  - 8 间角色房间均可访问且必填项齐全：名称、水果、头衔、性格一词、房间名、识别点、代表色、口头禅、1 张主图、≥5 张等比表情图、≥3 张姿势图；
  - 每位角色至少具备 **10 条**通过“不说的话”人工审核的投递回复；8 角色所有字段与最终定稿版本一致。
- **视觉与工程规范验收**
  - 准确呈现“柔和植绒微缩定格风 · 暖光森系树洞”的光影层次、手工木牌、柔绒圆角卡与火漆印章质感；

  - 手机（`390px`）与桌面端均无错位、截断或溢出；支持键盘焦点与 WCAG AA 对比度标准。
- **红线零遗留验收**
  - 公开页面零学号、零成员真实姓名、零模板撰写文字（如“撰写指南”“发表前删除此栏”）与占位图；
  - 全站零评论区、零自由发帖墙、零排行/点赞计数/PK、零商城/支付、零登录、零实时 AI 回复。

## 8. 明确不做的事（项目红线）

- 不做商城、在线支付与实物周边售卖（周边仅在角色房间展柜展示，不卖）。
